# Төлбөр (дансаар, гараар батлах) — тохиргоо

Тооцоолуур бүх хэрэглэгчид үнэгүй. **Үнийн санал, PDF, хэвлэх, и-мэйлээр илгээх** нь зөвхөн Pro эрхтэй хэрэглэгчид нээгдэнэ.

## Хэрхэн ажилладаг

1. Хэрэглэгч «🔒 Үнийн санал» эсвэл «⭐ Pro авах» дарна.
2. «Дансаар төлөх» дарахад таны данс, дүн, **өвөрмөц код** (жишээ: `PC-7F3K9Q`) гарна.
3. Хэрэглэгч шилжүүлэхдээ кодоо **гүйлгээний утгад** бичнэ.
4. Админ → **Төлбөр** таб дээр хүлээгдэж буй хүсэлт гарна. Банкны апп-аасаа код ба дүнг тулгаад **Батлах** дарна.
5. Pro эрх тэр даруй нээгдэнэ. Идэвхтэй эрх байвал хугацаан дээр нь нэмэгдэнэ.

Pro эрхийг **зөвхөн сервер** өгнө. Хэрэглэгч браузераас өөрийгөө Pro болгох, өөр хүний кодоор эрх авах боломжгүй (RLS + серверийн шалгалт).

## Нэг удаагийн тохиргоо

### 1. Supabase — SQL

Supabase → **SQL Editor** → `supabase/migrations/20261111_billing.sql` файлын агуулгыг бүхэлд нь хуулж → **Run**.
Дахин ажиллуулахад аюулгүй.

### 2. Vercel — Environment Variables

Vercel → print-calculator → **Settings → Environment Variables** (Production + Preview):

| Нэр | Жишээ | Тайлбар |
|---|---|---|
| `PAY_BANK_NAME` | Хаан банк | Төлбөр хүлээн авах банк |
| `PAY_ACCOUNT_NUMBER` | 5000123456 | Дансны дугаар |
| `PAY_ACCOUNT_NAME` | Д.Пүрэвдаш | Данс эзэмшигчийн нэр |
| `ADMIN_EMAILS` | you@gmail.com | Админ и-мэйл (олон бол таслалаар). Серверт л харагдана |
| `NEXT_PUBLIC_PRO_PRICE` | 199000 | Үнэ ₮ (заавал биш, анхдагч 199000) |
| `NEXT_PUBLIC_PRO_MONTHS` | 12 | Хугацаа сараар (заавал биш, анхдагч 12) |
| `SMTP_HOST` | smtp.gmail.com | И-мэйл илгээх сервер |
| `SMTP_PORT` | 465 | |
| `SMTP_USER` | you@gmail.com | |
| `SMTP_PASS` | (App password) | Gmail → Google Account → Security → 2-Step Verification → **App passwords** |
| `MAIL_FROM` | you@gmail.com | Илгээгчийн хаяг (Gmail бол SMTP_USER-тэй ижил) |

`SUPABASE_SERVICE_ROLE_KEY`, `NEXT_PUBLIC_SUPABASE_URL`, `NEXT_PUBLIC_SUPABASE_ANON_KEY` аль хэдийн байгаа.
Хувьсагч нэмсний дараа **Redeploy** хийнэ.

И-мэйл үйлчлүүлэгч рүү «Компанийн нэр (PrintCalc)» нэрээр очно. Хариу бичвэл профайлын «Холбоо барих и-мэйл» рүү очно.

## Хамгаалалт ба хязгаар

- `subscriptions`, `payment_requests`, `quotes`, `quote_emails` — хэрэглэгч зөвхөн өөрийнхийгөө **уншина**, бичихгүй.
- Нэг хэрэглэгч нэг л хүлээгдэж буй төлбөрийн хүсэлттэй. Өдөрт 5-аас олон хүсэлт үүсгэхгүй.
- Батлах нь 2 алхамтай, нэг хүсэлт 2 удаа батлагдахгүй.
- Үнийн санал өдөрт 200, и-мэйл өдөрт 30. PDF 3MB хүртэл, зөвхөн PDF файл.
- Серверийн алдааны дэлгэрэнгүйг хэрэглэгчид харуулахгүй (Vercel log-д бичнэ).
- Аюултай байсан QPay route-уудыг устгасан. QPay-д шилжих үед git түүхээс сэргээж, засаж ашиглана.

## Анхаарах

- PDF хэрэглэгчийн хөтөч дээр үүсдэг. Үнийн саналын албан ёсны дугаар, хадгалалт, и-мэйл серверээр Pro шалгаж байж олгогдоно.
- Хувийн данс руу орлого авбал и-баримт гаргах асуудлыг нягтлан бодогчоосоо лавлаарай.
